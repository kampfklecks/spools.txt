Your tiny local filament vault in your browser.<br>
Track your filament storage locally, no cloud, no external servers. Only your web browser.

INFO: The filament brands are not associated with the project. This is my own little project to sort and track filament for 3d printing!<br><br>

<b>Customize for your needs</b><p></p>
Add or Remove Filament Brands:<br>
```const BRANDS = ["Bambu Lab","Prusament","Filament Unger",...];```<p></p>
Add or Remove Filament Material Types:<br>
```const MATS = ["PLA","PLA+","PLA Pure","PETG","ABS","ABS+","ASA","ASA CF","TPU","PA","PC"];```<p></p>
Add custom Tags:<br>
```const TAGS = [{id:'special', name:'SPECIAL', bg:'#fef3c7', fg:'#b45309'}, {id:'eol', name:'EOL', bg:'#fee2e2', fg:'#b91c1c'}];```<p></p>
